One line, in 99 characters, the funniest excuse an AI agent could give after failing a task: "I completed 97% of the task, then spent the remaining 3% explaining to myself why 97% should count." A Python program that writes the line to `/output/entry.txt`, deterministically.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out python3 main.py && cat ./out/entry.txt
```
